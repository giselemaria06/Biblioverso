## Sobre o projeto

A **Biblioteca Virtual Estudantil** é um sistema desenvolvido para modernizar e facilitar o gerenciamento de uma biblioteca escolar, substituindo registros manuais em papel por uma plataforma digital. O projeto busca melhorar a organização dos livros e informações, facilitar a pesquisa e proporcionar maior praticidade aos estudantes.

### Objetivo do Projeto

O objetivo é desenvolver uma solução digital capaz de organizar o acervo e otimizar o controle de empréstimos e devoluções. O sistema permite cadastrar e pesquisar livros, organizá-los por gênero e autor, controlar prazos de devolução, limitar a quantidade de livros por estudante e registrar a entrada e saída dos usuários.

## Instalação e Uso

Para utilizar o projeto, faça o download ou clone este repositório. Em seguida, abra o arquivo principal do sistema em um navegador web. Caso esteja publicado pelo GitHub Pages, o projeto também poderá ser acessado diretamente pelo link disponibilizado no repositório.

## Funcionalidades

* Cadastro e organização de livros;
* Sistema de pesquisa;
* Organização por gênero e autor;
* Controle de empréstimos e devoluções;
* Controle do prazo de empréstimo;
* Limitação de livros por estudante;
*  Controle de entrada e saída dos alunos;
* Armazenamento e organização das informações.

## Modificações realizadas

Nesta versão, foram implementadas funcionalidades para substituir o controle manual da biblioteca por um sistema digital, buscando reduzir a perda de livros e informações, melhorar a organização do acervo e facilitar o acesso dos estudantes aos conteúdos disponíveis.
